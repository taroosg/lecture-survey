# Screen: 講義作成画面

## 1. 画面の目的

新しい講義を作成するためのフォームを提供する。

## 2. 前提条件

- ユーザーが認証済みであること

## 3. 主な要素（UI要素）

- パンくずリスト
- ページタイトル「新しい講義を作成」
- 講義フォーム（LectureFormコンポーネント）
  - タイトル入力フィールド（必須）
  - 講義日入力フィールド（必須）
  - 講義時間入力フィールド（必須）
  - 講義概要入力フィールド（任意）
  - アンケート締切日入力フィールド（必須）
  - アンケート締切時間入力フィールド（必須）
  - 「講義を作成」ボタン
  - 「キャンセル」ボタン

## 4. 主な操作

- 各フィールドに講義情報を入力する
- 「講義を作成」ボタンをクリックして講義を登録する
- 「キャンセル」ボタンをクリックして講義一覧画面に戻る

## 5. 遷移元・遷移先

- from:
  - ダッシュボード画面
  - 講義一覧画面
- to:
  - 講義一覧画面（作成成功時またはキャンセル時）
