# Screen: サインイン画面

## 1. 画面の目的

ユーザーがシステムにサインインまたはサインアップするための認証フォームを提供する。

## 2. 前提条件

- 特になし（未認証ユーザーがアクセス可能）

## 3. 主な要素（UI要素）

- 画面説明テキスト「Log in to see the numbers」
- メールアドレス入力フィールド
- パスワード入力フィールド
- サインイン/サインアップボタン
- サインイン/サインアップ切り替えリンク
- エラーメッセージ表示エリア

## 4. 主な操作

- メールアドレスとパスワードを入力する
- 「Sign in」または「Sign up」ボタンをクリックして認証を行う
- 「Sign up instead」または「Sign in instead」リンクをクリックしてモードを切り替える

## 5. 遷移元・遷移先

- from:
  - ダッシュボード画面（サインアウト時）
  - 直接アクセス
- to:
  - ダッシュボード画面（認証成功時）
