# Screen: ダッシュボード画面

## 1. 画面の目的

認証済みユーザーのホーム画面として、主要機能へのナビゲーションを提供する。

## 2. 前提条件

- ユーザーが認証済みであること

## 3. 主な要素（UI要素）

- ページタイトル「ダッシュボード」
- 講義作成カード（アイコン、タイトル、説明、リンク）
- 講義一覧カード（アイコン、タイトル、説明、リンク）

## 4. 主な操作

- 「講義作成」カードをクリックして講義作成画面に遷移する
- 「講義一覧」カードをクリックして講義一覧画面に遷移する

## 5. 遷移元・遷移先

- from:
  - サインイン画面（認証成功時）
- to:
  - 講義作成画面
  - 講義一覧画面
