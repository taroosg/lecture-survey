# Screen: 講義詳細画面

## 1. 画面の目的

講義の詳細情報を表示し、分析結果の確認や各種操作へのアクセスを提供する。

## 2. 前提条件

- ユーザーが認証済みであること
- 指定された講義IDが存在すること

## 3. 主な要素（UI要素）

- パンくずリスト
- ページタイトル「講義詳細」
- 講義情報カード（タイトル、編集ボタン、講義日時、アンケート締切、ステータスバッジ、回答件数、講義概要）
- アクションボタン群（回答データを確認、アンケートを開く、URLをコピー）
- アンケートURL表示エリア
- 分析結果セクション（分析完了時のみ表示）
- 分析タブナビゲーション（サマリー/基本統計/クロス集計）
- 分析結果コンテンツ（SatisfactionSummary/BasicStatsGrid/CrossAnalysisChartsContainer）

## 4. 主な操作

- 「編集」ボタンをクリックして講義編集画面に遷移する
- 「回答データを確認」ボタンをクリックして回答一覧画面に遷移する
- 「アンケートを開く」ボタンをクリックしてアンケート回答画面を新しいタブで開く
- 「URLをコピー」ボタンでアンケートURLをクリップボードにコピーする
- 分析タブをクリックして表示する分析結果を切り替える

## 5. 遷移元・遷移先

- from:
  - 講義一覧画面
- to:
  - 講義編集画面
  - アンケート回答画面（新しいタブ）
