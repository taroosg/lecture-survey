# Screen: 講義編集画面

## 1. 画面の目的

既存の講義情報を編集・削除するためのフォームを提供する。

## 2. 前提条件

- ユーザーが認証済みであること
- 指定された講義IDが存在すること

## 3. 主な要素（UI要素）

- パンくずリスト
- ページタイトル「講義を編集」
- 現在の状態表示（ステータスバッジ）
- 講義フォーム（LectureFormコンポーネント）
  - タイトル入力フィールド（必須）
  - 講義日入力フィールド（必須）
  - 講義時間入力フィールド（必須）
  - 講義概要入力フィールド（任意）
  - アンケート締切日入力フィールド（必須）
  - アンケート締切時間入力フィールド（必須）
  - 「講義を更新」ボタン
  - 「キャンセル」ボタン
- Danger Zoneセクション
  - 削除に関する警告メッセージ
  - 削除対象データの説明リスト
  - 「この講義を削除」ボタン（受付中の講義は無効化）
- 削除確認モーダル（DeleteConfirmationModal）
  - 講義タイトル入力フィールド
  - 「削除する」ボタン
  - 「キャンセル」ボタン

## 4. 主な操作

- 各フィールドの講義情報を編集する
- 「講義を更新」ボタンをクリックして講義を更新する
- 「キャンセル」ボタンをクリックして講義一覧画面に戻る
- 「この講義を削除」ボタンをクリックして削除確認モーダルを開く
- 削除確認モーダルで講義タイトルを入力して「削除する」ボタンをクリックする

## 5. 遷移元・遷移先

- from:
  - 講義詳細画面
- to:
  - 講義一覧画面（更新成功時、削除成功時、またはキャンセル時）
