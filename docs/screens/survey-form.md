# Screen: アンケート回答画面

## 1. 画面の目的

受講者が講義に対するフィードバックを送信するためのアンケートフォームを提供する。

## 2. 前提条件

- 講義のステータスが「受付中（active）」であること
- アンケートURLにアクセスできること（認証不要）

## 3. 主な要素（UI要素）

- アンケートヘッダー（講義タイトル、講義日時、講義説明）
- 性別選択（ラジオボタン：男性/女性/その他/回答しない）
- 年代選択（ラジオボタン：10代/20代/30代/40代/50代/60代以上）
- 理解度評価（ラジオボタン：1〜5の5段階）
- 満足度評価（ラジオボタン：1〜5の5段階）
- 自由コメント入力欄（テキストエリア、任意）
- 「回答を送信」ボタン
- 匿名性に関する説明文
- 回答完了画面（送信成功時に表示）
- アンケート利用不可画面（講義が受付中でない場合に表示）

## 4. 主な操作

- 性別を選択する
- 年代を選択する
- 理解度を5段階で選択する
- 満足度を5段階で選択する
- 自由コメントを入力する（任意）
- 「回答を送信」ボタンをクリックして回答を送信する

## 5. 遷移元・遷移先

- from:
  - 外部（教員から共有されたURL）
  - 講義詳細画面（アンケートを開くボタン）
- to:
  - なし（回答完了後は同画面に完了メッセージを表示）
