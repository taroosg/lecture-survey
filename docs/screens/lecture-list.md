# Screen: 講義一覧画面

## 1. 画面の目的

登録済みの講義を一覧で表示し、講義の検索・フィルタリング・管理を行う。

## 2. 前提条件

- ユーザーが認証済みであること

## 3. 主な要素（UI要素）

- パンくずリスト
- ページタイトル「講義一覧」
- 「新しい講義を作成」ボタン
- フィルター・検索パネル（状態フィルタ、テキスト検索、ソートボタン）
- 検索結果件数表示
- 講義カード一覧（タイトル、説明、日時、ステータス、アンケートURL、分析結果プログレスバー）
- ページネーション（前へ/次へボタン、ページ番号表示）

## 4. 主な操作

- 「新しい講義を作成」ボタンをクリックして講義作成画面に遷移する
- 状態フィルタで講義を絞り込む（すべて/受付中/締切済み/分析完了）
- 検索フィールドでタイトル・説明文を検索する
- ソートボタンで並び順を変更する（作成日/講義日/タイトル、昇順/降順）
- 講義カードをクリックして講義詳細画面に遷移する
- 「URLコピー」ボタンでアンケートURLをクリップボードにコピーする
- ページネーションで表示ページを切り替える

## 5. 遷移元・遷移先

- from:
  - ダッシュボード画面
  - 講義作成画面（作成成功時）
  - 講義編集画面（更新/削除成功時）
- to:
  - 講義作成画面
  - 講義詳細画面
