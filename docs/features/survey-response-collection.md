# Feature: アンケート回答収集

## 1. 概要

受講者が講義に対するフィードバックを匿名で送信できる機能を提供する。

## 2. 前提条件

- 講義のステータスが「受付中（active）」であること
- アンケートURLにアクセス可能であること（認証不要）

## 3. ユースケース（機能単位）

- アンケート回答：受講者が講義の評価（理解度、満足度等）を送信する
- アンケート利用可否確認：アクセス時に回答可能かどうかを判定する

## 4. 仕様（システムの振る舞い）

- アンケートは匿名で回答できる（認証不要）
- 回答項目は性別、年代、理解度（5段階）、満足度（5段階）、自由コメント（任意）
- 性別、年代、理解度、満足度は必須項目
- 自由コメントは任意項目
- 講義が「受付中」以外の場合は回答不可メッセージを表示する
- 回答送信成功時は完了メッセージを表示する
- 回答データにはユーザーエージェント情報が記録される
