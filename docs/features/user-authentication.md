# Feature: ユーザー認証

## 1. 概要

教員がシステムにアクセスするための認証機能を提供する。メールアドレスとパスワードによる認証方式を採用。

## 2. 前提条件

- ユーザーがメールアドレスを持っていること
- サインアップ済みのユーザーのみサインイン可能

## 3. ユースケース（機能単位）

- サインアップ：新規ユーザーがメールアドレスとパスワードでアカウントを作成する
- サインイン：登録済みユーザーがメールアドレスとパスワードで認証する
- サインアウト：認証済みユーザーがセッションを終了する

## 4. 仕様（システムの振る舞い）

- Convex Authを使用したパスワード認証を行う
- 認証成功時はダッシュボード画面にリダイレクトする
- サインアウト時はサインイン画面にリダイレクトする
- 認証エラー時はエラーメッセージを表示する
- ヘッダーに認証状態に応じたサインアウトボタンを表示する
