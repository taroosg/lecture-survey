# Feature: 講義一覧表示

## 1. 概要

登録済みの講義を一覧で表示し、検索・フィルタリング・ソート機能により効率的に講義を探せる機能を提供する。

## 2. 前提条件

- ユーザーが認証済みであること

## 3. ユースケース（機能単位）

- 講義一覧閲覧：登録済みの講義を一覧で確認する
- ステータスフィルタリング：受付中/締切済み/分析完了でフィルタリングする
- テキスト検索：タイトルや説明文で講義を検索する
- ソート：作成日/講義日/タイトルで並び替える
- ページネーション：大量の講義を分割して表示する

## 4. 仕様（システムの振る舞い）

- 1ページあたり10件の講義を表示する
- デフォルトのソート順は講義日の降順
- フィルタリング/検索/ソート変更時はページを1に戻す
- 受付中の講義にはアンケートURLとコピーボタンを表示する
- 分析完了の講義には理解度・満足度のプログレスバーを表示する
- 各講義カードは講義詳細画面へのリンクとなる
- 講義が0件の場合は講義作成を促すメッセージを表示する
- 検索結果が0件の場合は該当なしメッセージを表示する
