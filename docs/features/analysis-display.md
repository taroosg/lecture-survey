# Feature: 分析結果表示

## 1. 概要

アンケート回答の集計・分析結果を教員に提供し、講義改善に役立てるための機能。

## 2. 前提条件

- ユーザーが認証済みであること
- 講義のステータスが「分析完了（analyzed）」であること

## 3. ユースケース（機能単位）

- サマリー表示：理解度・満足度の概要を確認する
- 基本統計表示：回答の詳細な統計情報を確認する
- クロス集計表示：属性（性別、年代）別の分析結果を確認する

## 4. 仕様（システムの振る舞い）

- 講義詳細画面にタブ形式で3種類の分析結果を表示する
- サマリータブ：理解度と満足度の平均評価をビジュアル表示する
- 基本統計タブ：各質問項目の回答分布や平均値を表示する
- クロス集計タブ：性別×理解度、年代×満足度などの属性別分析を表示する
- 分析結果は締切後のバッチ処理で自動生成される
- 講義一覧画面では分析完了した講義に理解度・満足度のプログレスバーを表示する
