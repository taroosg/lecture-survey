# Feature: 講義管理

## 1. 概要

教員が講義情報の作成・編集・削除を行うための機能を提供する。講義には自動的にアンケートが紐づけられる。

## 2. 前提条件

- ユーザーが認証済みであること

## 3. ユースケース（機能単位）

- 講義作成：新しい講義を登録し、アンケートを発行する
- 講義編集：既存の講義情報（タイトル、日時、締切等）を更新する
- 講義削除：講義と関連データ（回答、分析結果）を完全に削除する

## 4. 仕様（システムの振る舞い）

- 講義作成時に必須項目（タイトル、講義日時、アンケート締切日時）を入力する
- 講義作成時にステータスは自動的に「受付中（active）」となる
- アンケート締切日時を過ぎると自動的にステータスが「締切済み（closed）」に変更される
- 締切後に分析が完了するとステータスが「分析完了（analyzed）」に変更される
- 受付中（active）の講義は削除できない
- 講義削除時は関連する回答データ・分析結果も同時に削除される
- 削除時は確認モーダルで講義タイトルの入力を求める
