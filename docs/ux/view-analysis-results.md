# UX: 分析結果を確認する

## 1. 目的

教員がアンケート回答の分析結果（基本統計、クロス集計、サマリー）を確認し、講義改善に役立てる。

## 2. 対象ユーザー

教員（role: "user"）

## 3. フロー（ユーザー行動）

1. 講義一覧画面でステータスが「分析完了」の講義を確認する
2. 講義をクリックして講義詳細画面にアクセスする
3. 分析結果セクションのタブ（サマリー/基本統計/クロス集計）を切り替えて確認する

## 4. 完了状態（成功条件）

- サマリータブで理解度・満足度の評価が確認できている
- 基本統計タブで詳細な統計情報が確認できている
- クロス集計タブで属性別の分析結果が確認できている
