# UX: 講義一覧を確認する

## 1. 目的

教員が登録済みの講義を一覧で確認し、講義の状態や回答状況を把握する。

## 2. 対象ユーザー

教員（role: "user"）

## 3. フロー（ユーザー行動）

1. ダッシュボードから「講義一覧」をクリックする
2. 講義一覧画面で登録済みの講義を確認する
3. 必要に応じてフィルタリング（状態別）や検索（タイトル、説明文）を行う
4. 必要に応じてソート（作成日、講義日、タイトル）を切り替える

## 4. 完了状態（成功条件）

- 登録済みの講義が一覧表示されている
- 各講義のステータス（受付中/締切済み/分析完了）が確認できている
- 分析完了の講義では理解度・満足度のプログレスバーが表示されている
