# UX: システムにログインする

## 1. 目的

教員がシステムにアクセスし、講義管理機能を利用できる状態にする。

## 2. 対象ユーザー

教員（role: "user"）

## 3. フロー（ユーザー行動）

1. サインイン画面にアクセスする
2. メールアドレスとパスワードを入力する
3. 「Sign in」ボタンをクリックする
4. ダッシュボード画面に自動遷移する

## 4. 完了状態（成功条件）

- ダッシュボード画面が表示されている
- ヘッダーにサインアウトボタンが表示されている
- 講義作成・講義一覧へのナビゲーションが利用可能な状態
