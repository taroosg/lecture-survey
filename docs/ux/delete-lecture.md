# UX: 講義を削除する

## 1. 目的

教員が不要になった講義とその関連データ（回答、分析結果）を完全に削除する。

## 2. 対象ユーザー

教員（role: "user"）

## 3. フロー（ユーザー行動）

1. 講義一覧画面から対象の講義の詳細画面にアクセスする
2. 講義詳細画面の「編集」ボタンをクリックする
3. 講義編集画面下部の「Danger Zone」にある「この講義を削除」ボタンをクリックする
4. 削除確認モーダルで講義タイトルを入力して確認する
5. 「削除する」ボタンをクリックする
6. 講義一覧画面に自動遷移する

## 4. 完了状態（成功条件）

- 講義一覧画面から対象の講義が消えている
- 関連する回答データと分析結果も削除されている
