# UX: アンケートに回答する

## 1. 目的

受講者が講義に対するフィードバック（理解度、満足度、コメント）を送信する。

## 2. 対象ユーザー

受講者（匿名ユーザー）

## 3. フロー（ユーザー行動）

1. 教員から共有されたアンケートURLにアクセスする
2. アンケートフォームで各項目に回答する（性別、年代、理解度、満足度、自由コメント）
3. 「回答を送信」ボタンをクリックする
4. 送信完了画面が表示される

## 4. 完了状態（成功条件）

- 「回答ありがとうございました」の完了メッセージが表示されている
- 回答データがシステムに保存されている
