# UX: アンケートを配布する

## 1. 目的

教員が受講者にアンケートURLを共有し、フィードバックを収集できる状態にする。

## 2. 対象ユーザー

教員（role: "user"）

## 3. フロー（ユーザー行動）

1. 講義一覧画面または講義詳細画面でアンケートURLを確認する
2. 「URLコピー」ボタンをクリックしてURLをクリップボードにコピーする
3. コピーしたURLを受講者に共有する（メール、LMS、チャット等）

## 4. 完了状態（成功条件）

- アンケートURLがクリップボードにコピーされている
- 受講者がそのURLからアンケートに回答できる状態になっている
