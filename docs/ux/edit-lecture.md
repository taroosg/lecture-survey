# UX: 講義情報を編集する

## 1. 目的

教員が既存の講義情報（タイトル、日時、締切など）を修正する。

## 2. 対象ユーザー

教員（role: "user"）

## 3. フロー（ユーザー行動）

1. 講義一覧画面または講義詳細画面から対象の講義にアクセスする
2. 講義詳細画面の「編集」ボタンをクリックする
3. 講義編集画面で必要な情報を修正する
4. 「講義を更新」ボタンをクリックする
5. 講義一覧画面に自動遷移する

## 4. 完了状態（成功条件）

- 講義情報が更新されている
- 講義一覧画面で更新後の情報が確認できる
