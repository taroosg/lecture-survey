# UX: 講義を作成する

## 1. 目的

教員が新しい講義とそれに紐づくアンケートを登録し、受講者からのフィードバックを収集できる状態にする。

## 2. 対象ユーザー

教員（role: "user"）

## 3. フロー（ユーザー行動）

1. ダッシュボードまたは講義一覧画面から「講義作成」または「新しい講義を作成」をクリックする
2. 講義作成画面で必要な情報を入力する（タイトル、講義日時、アンケート締切日時など）
3. 「講義を作成」ボタンをクリックする
4. 講義一覧画面に自動遷移する

## 4. 完了状態（成功条件）

- 講義一覧画面に作成した講義が表示されている
- 作成した講義のステータスが「受付中」となっている
- アンケートURLが発行されている
